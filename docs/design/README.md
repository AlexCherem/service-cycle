# Дизайн Service Cycle

`service-cycle-ui-concept.pptx` — исходный UI-концепт продукта из 8 слайдов.

В презентации показаны:

- регистрация компании;
- импорт клиентской базы;
- связь клиентов с оборудованием;
- настройка сервисного цикла;
- обработка откликов и задач сотрудников;
- клиентская страница ответа без регистрации;
- обзор результатов для руководителя.

`overview.png` — быстрый предпросмотр всех экранов.

Материалы в этой папке служат дизайн-референсом. Рабочие изображения, которые
непосредственно загружаются frontend-приложением, следует хранить в
`apps/web/public`.

## Известные особенности

- В исходной презентации заголовок на слайде 4 обрезан слева.
